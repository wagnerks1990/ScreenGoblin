# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository. If that feature is unavailable, contact the repository owner privately and request a secure reporting channel without including exploit details in the first message.

Include the affected version/commit, impact, reproduction steps, and any suggested mitigation. Do not access other users' data, degrade services, or perform social engineering. We will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.

## Supported versions

Until the first stable release, only the current default branch is supported. This prototype must not be used as a certified emergency or life-safety system.

Never commit credentials, signing keys, student information, production screenshots, or database dumps. Rotate a secret immediately if it is exposed, even if the commit is later removed.
