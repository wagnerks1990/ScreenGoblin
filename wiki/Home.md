# ScreenGoblin

ScreenGoblin is an Android-first digital-signage prototype with a Content Studio and Operations Console, a control-plane API, and an offline-capable Player.

The current release is pre-production. Only an isolated, non-PII, non-life-safety pilot is permitted. Emergency activation remains disabled. CI evidence does not authorize production deployment or certify physical-device behavior.
