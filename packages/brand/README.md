# ScreenGoblin brand resources

This package is the code-facing source for ScreenGoblin design tokens and approved brand artwork. Preserve image aspect ratios and use the full horizontal logo at 160 pixels or wider. The mascot belongs in onboarding, empty states, marketing, and selected success states—not dense operational tables or serious error states.

## UX reference renderings

`reference/01-dashboard.svg`, `02-screen-fleet.svg`, `03-playlists.svg`, and `04-schedules.svg` are the approved ScreenGoblin Console visual references. They are version-controlled SVG design artifacts so GitHub and text-oriented development tools can review them directly. See `docs/UX_REFERENCE.md` for scope and implementation rules.

These SVGs are design documentation only. They do not enable SVG or web content in the ScreenGoblin Player media pipeline, and synthetic values shown in them are not production data or implemented-feature evidence.
