# ScreenGoblin documentation

ScreenGoblin is an Android-first digital-signage prototype. Only an isolated,
non-PII, non-life-safety pilot is permitted. Emergency publishing remains disabled
until every release gate is satisfied. Documentation is maintained in Git and
this page is synchronized from the protected default branch.

- [Getting started](https://github.com/wagnerks1990/ScreenGoblin/blob/main/README.md)
- [Documentation index](https://github.com/wagnerks1990/ScreenGoblin/blob/main/docs/README.md)
- [Preproduction release gates](https://github.com/wagnerks1990/ScreenGoblin/blob/main/docs/PREPRODUCTION.md)
- [Operating runbook](https://github.com/wagnerks1990/ScreenGoblin/blob/main/docs/RUNBOOK.md)
- [Threat model](https://github.com/wagnerks1990/ScreenGoblin/blob/main/docs/THREAT_MODEL.md)
- [Device protocol](https://github.com/wagnerks1990/ScreenGoblin/blob/main/docs/DEVICE_PROTOCOL.md)

The repository documents are canonical. Conceptual layouts and passing builds do
not establish production readiness or authorization to operate physical devices.
